## Featured Projects

### AuthentiScan AI
Fake product and review detection SaaS — final-year capstone project.
- MobileNetV2 for product image classification
- Logistic Regression + TF-IDF for fake review detection
- Full-stack app (Flask backend) with a dual-model SPA ("VerifyAI") combining both classifiers
- Dedicated SaaS landing page, dark premium UI

### InterviewStack
Interview preparation platform covering ML/AI, Software Engineering, System Design, and Computer Networks.
- Rebuilt from React/Vite/Tailwind/Zustand into a lighter vanilla JS + localStorage architecture
- Student history tracking, skill-gap reporting, profile dashboard

### NEXUS
AI-powered screen time analyzer.
- Three.js orbital visualizations of social media usage
- GSAP-driven scroll animation

### Chronicle
Time-tracking productivity app with an analog, ink-fill clock visualization — rebuilt for a more refined, human feel over the original version.
